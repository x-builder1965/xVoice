機能別コントロール・キー操作・マウス操作対応表
機能 コントロール キー操作 マウス操作 説明
ヘッダー
　・アプリ名 なし なし なし ・アプリ名のクリックでヘルプを表示。ヘルプ画面の❌で戻る
　・バージョン なし なし なし ・バージョンのクリックで変更履歴を表示。変更履歴画面の❌で戻る
　・テーマ切替 ☀️／🌙 Ctrl+t なし ・画面のテーマをライト（☀️）／ダーク（🌙）で切り替え
エンジンパネル
　・話者リスト Drop-down なし なし ・読み上げ音声のモデルを選択
　・エンジン接続・切断 🔄 Ctrl+n なし ・AivisSpeech Engineに接続中（赤）・切断中（青）。
　・エンジンアドレス Text Box なし なし ・接続先のAivisSpeech EngineのURLを入力。ローカルアドレス：http://127.0.0.1:10101
テキストパネル
　・フォントサイズ選択 Drop-down なし なし ・テキストのフォントサイズを「小：12px／中：16px／大：20px／特大：24px」から選択
　・テキスト向き選択 Drop-down なし なし ・テキストの向きを「横向き／縦向き」から選択
　・フォルダ選択 📁 Ctrl+d なし ・テキストファイル（.txt）・プレイリストファイル（.amppl）が格納されているフォルダを選択
　・ファイル選択 🗒️ Ctrl+f なし ・読み上げる複数テキストファイル（.txt）・プレイリストファイル（.amppl）を選択
　・読み上げプレイリスト Drop-down なし なし ・読み上げテキストのプレイリスト。
　・読み編集 🖊️ Ctrl+h なし ・選択した文章の読みを変更するためのルビ（｛文章｜読み｝）を付加・解除
　・統一編集 🔠 Ctrl+u なし ・選択した読み編集と同じ文章を同じ読みに設定
　・読み編集検索 🔍 Ctrl+a なし ・読み編集された箇所を順次検索
　・ファイル保存 💾 Ctrl+s なし ・テキストをファイルに保存。テキストの変更なし（青）、変更あり（赤）を表示
　・プレイリスト保存 📚 Ctrl+l なし ・プレイリストをプレイリストファイル（.amppl）で保存
　・ファイルクリア 🗑️ Ctrl+c なし ・テキストを全てクリア
　・読み上げテキスト Text Box なし なし ・編集可能な読み上へ対象のテキスト文章
再生操作パネル
　・前ファイルへ ⏮️ Ctrl+PgDown なし ・プレイリスト上の１つ前ファイルへ移動
　・前１０行へ ⏪ Ctrl+← なし ・現在行の１０行前へ移動
　・再生／停止 ▶️／⏹️ Ctrl+Space なし ・テキストの読み上げ再生（▶️：青）と停止（⏹️：赤）の切替
　・次１０行へ ⏩ Ctrl+→ なし ・現在行の１０行次へ移動
　・次ファイルへ ⏭️ Ctrl+PgDown なし ・プレイリスト上の１つ次ファイルへ移動
　・生成／中止 🎤 Ctrl+g なし ・テキストから合成音声ファイル（mp3）の生成開始（青）と生成中止（赤）の切替
　・音声ミュート 🔊／🔇 Ctrl+m なし ・音声のミュート設定／解除
　・音量変更バー なし Atl+↑ / Alt+↓ Alt+wheel ・スライダーで音量変更。再生中 Alt+↑：音量アップ、Alt+↓：音量ダウン。
　・再生速度変更 Drop-down Ctrl+.／Ctrl+, なし ・再生速度を0.25×〜5.0×の間で変更できます。
　・キャッシュ数変更バー なし Ctrl+↑ / Ctrl+↓ Ctrl+wheel ・スライダーでキャッシュ数変更。再生中 Ctrl+↑：キャッシュ数アップ、Ctrl+↓：キャッシュ数ダウン。
その他の機能
　・ドラッグ＆ドロップ なし なし なし ・フォルダ・テキストファイル（.txt）・プレイリストファイル（.amppl）のドロップでプレイリストに追加
